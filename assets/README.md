# Project artwork

The three PNGs in this directory were created with the built-in OpenAI image generation tool for this independent community project. They are original illustrations, not official Hermes or NousResearch branding.

| File | Use | Prompt summary |
| --- | --- | --- |
| `logo.png` | Square transparent project mark | Abstract H, heartbeat pulse and terminal cursor; navy, cyan, mint and amber; no text or official marks. |
| `hero.png` | README introduction | Wide conceptual illustration of a terminal connected to a local diagnostics dashboard; no text or official marks. |
| `recovery-guide.png` | Four-step guide poster | Landscape infographic with the exact labels “CHECK”, “BACK UP”, “RESTART”, “VERIFY”, plus “Your data stays on your machine”. |

The English and Persian README files explain the poster steps in full. The generated dashboard in `hero.png` is illustrative, not a screenshot of a specific software version.
